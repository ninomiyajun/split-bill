# 製品の前提

このプロジェクトの製品の前提（目的、対象の利用者、作らないもの）の正本。新しい機能や画面を考えるときに読む。
中身は利用者が決める。仕様の担当は、この文書を書き換えず、変えるべき点を案として返す。仕様の書式は
[製品の仕様（書式と目録）](product-specs/README.md) にある。

## 目的

割り勘のときに、1 人あたりの額と端数を誰が払うかを、迷わずにすぐ出すこと。

## 対象の利用者

会計の場にいる幹事などが、手元のスマートフォンやパソコンのブラウザで、その場で使う。

## 作らないもの

- 外部の API・API キー・有料のサービス（費用と、鍵の管理と、外への通信を持ち込まないため）
- 入れた値の保存と履歴（その場で使い捨てる計算で、残す必要が無いため）
- ログイン（保存するものが無く、利用者を区別する必要が無いため）
- 参加者の名前の入力（均等に割るだけなら、人数だけで足りるため）
- 傾斜の割り勘（人ごとに額を変える割り方）
- 円以外の通貨
- 税やサービス料の計算
