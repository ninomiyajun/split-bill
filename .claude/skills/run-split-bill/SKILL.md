# split-bill の起動・確認・停止

パスはすべてリポジトリの根からの相対である。

## 前提

- Node.js の 24 系か 26 系以上（検証の基準は `.nvmrc` の 24 系。25 系は依存が対象外にしているので使わない）と npm を使う。
- 依存は `npm ci` で入れる。
- 待ち受けは `127.0.0.1` に限る。ポートは 3000 から順に、`lsof -nP -iTCP:<ポート> -sTCP:LISTEN` の出力が空の番号を選ぶ。

## 起動のコマンド

- 開発の形: `npm run dev -- --hostname 127.0.0.1 --port <ポート>`
- 本番の形: `npm run build` の後に `npm run start -- --hostname 127.0.0.1 --port <ポート>`
  （`-H` と `-p` の名前は `node_modules/next/dist/docs/01-app/03-api-reference/06-cli/next.md` の `next dev` と `next start` の
  オプションの表で確かめた）
- どちらも止まらずに動き続けるので、バックグラウンドで起動し、起動した処理の識別子を控える。

## 起動の完了の確かめ方

出力に `Ready` の行が出て、`curl -sS -o /dev/null -w '%{http_code}' http://127.0.0.1:<ポート>/` が `200` を返す。

## 止め方と止まったことの確かめ方

- 自分が起動したバックグラウンドの処理を、控えた識別子で止める。プロセスの名前で探して止めない（ほかの会話が起動したものを
  止めないため）。
- 止まったことは、上の `curl` が接続できずに失敗し、上の `lsof` の出力が空になることで確かめる。

## 確認用のデータで起動する方法

なし（画面で値を入れるだけで、データを読まず、外部へ通信しない）。
